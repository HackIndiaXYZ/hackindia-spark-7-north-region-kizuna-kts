# 🚗 Rear Car Communicator

## Overview
The **Rear Car Communicator** is a low-cost road safety project designed to improve communication between vehicles. It helps drivers behind understand the actions of the front vehicle using clear LED signals.

This project is especially useful for:

- Highways  
- Hilly Areas  
- Blind Turns  
- Foggy Roads  
- Night Driving  

---

## Problem Statement
Many road accidents happen because rear drivers cannot understand what the front vehicle is going to do.

Common problems:

- Unsafe overtaking  
- Sudden braking without warning  
- No clear communication between vehicles  
- Low visibility in fog or night  
- Confusion on mountain roads and highways  

---

## Solution
Our project uses an **LED Matrix Display** mounted on the rear side of the vehicle.  
By pressing physical buttons, the driver can display signals for the rear vehicle.

---

## Button Functions

| Button | Function |
|--------|----------|
| Button 1 | Pass Left |
| Button 2 | Pass Right |
| Button 3 | Stop / Wait |
| Button 4 | Clear / Normal Mode |

---

## Hardware Components Used

- Arduino UNO  
- MAX7219 LED Matrix Display  
- 4 Push Buttons  
- Jumper Wires  
- Breadboard / PCB  

---

## Software Used

- Arduino C++ Programming Language  

---

## Working Principle

1. Driver presses one of the buttons.
2. Arduino reads button input.
3. Corresponding message/symbol appears on LED Matrix.
4. Rear vehicle driver understands instruction.
5. Safer communication between vehicles.
